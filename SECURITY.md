# Sicherheit

Dieses Repository enthält eine statische Website und Lehrmaterialien. Es verarbeitet keine Nutzerdaten.

## Eine Schwachstelle melden

Melden Sie Sicherheitsprobleme, zum Beispiel in den GitHub-Workflows, nicht in einem öffentlichen Issue. Verwenden Sie die Funktion [Report a vulnerability](https://github.com/maehr/diskriminierungssensible-metadatenpraxis-problembewusstsein-workshop/security/advisories/new). Beschreiben Sie das Problem, die Schritte zur Reproduktion und, falls bekannt, eine mögliche Lösung.

> **English summary.** Report security issues privately through GitHub's "Report a vulnerability" feature, not in a public issue.
